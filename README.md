# MPPI-Footstep Planning for Quadruped Robots

## Project Overview

This repository contains my Master's Dissertation research work at University College London (UCL). The project focuses on applying Model Predictive Path Integral (MPPI) control to quadruped robot footstep planning, with the goal of achieving more diverse maneuverability by randomizing foot placement timing and positions.

This work builds upon the [Quadruped-PyMPC](https://github.com/iit-DLSLab/Quadruped-PyMPC) framework developed by IIT-DLSLab.
